# QuotaRing

**在 Windows 任务栏查看 Codex 剩余额度。**

QuotaRing（额度环）是一款非官方的 Windows Codex 额度显示工具。它在主任务栏右侧、系统通知区域左边显示额度圆环和剩余百分比，点击后在上方展开详情卡片，方便随时查看额度与重置时间。

> **当前状态：首发版本准备中。** 计划首发版本为 **v1.0.0**。当前仓库先提供项目说明，源代码和 Windows 安装包尚未上传；下面的下载、安装与卸载步骤供安装包发布后使用。

[查看下载与版本发布](https://github.com/huang0732/QuotaRing/releases) · [反馈问题](https://github.com/huang0732/QuotaRing/issues)

## 功能介绍

- **任务栏显示额度：** 圆环和百分比表示 Codex 剩余额度。
- **点击查看详情：** 在显示条正上方展开详情卡，显示额度周期、剩余比例、重置时间，以及服务端提供的重置卡数量和最近到期信息。
- **显示重置倒计时：** 用 5 个小圆点表示五小时窗口剩余的小时数，用 7 个小竖条表示周窗口剩余的天数。
- **独立后台读取：** 安装完成后，关闭 Codex 桌面窗口仍可继续读取额度；本机登录信息、网络和额度查询服务需要保持可用。
- **随 Windows 登录启动：** 默认自动显示，无需通过额外的桌面入口启动 Codex。
- **跟随使用环境显示：** 任务栏自动隐藏时跟随隐藏，全屏视频或游戏时暂时隐藏，恢复普通窗口后重新显示。
- **显示适配：** 任务栏显示条根据任务栏高度和系统显示缩放调整大小，详情卡按内容计算尺寸，并支持系统明暗主题。目前尚未专门适配 Windows 的独立“文本大小”设置。

QuotaRing 显示的是 **Codex 的账号额度**，不显示普通 ChatGPT 聊天的剩余消息次数。

## 系统与运行要求

| 项目 | 说明 |
| --- | --- |
| Windows 11 x64 | 已在开发者当前设备上实际使用并确认显示效果。 |
| Windows 10 x64 | 属于兼容目标，尚未经过实机验证。 |
| 其他平台与架构 | 当前不提供 macOS、Linux 或 ARM64 专用安装包。 |
| Node.js | 需要 **24 或更新版本**，可从 [Node.js 官网](https://nodejs.org/en/download)下载安装。 |
| 显示运行组件 | 需要 .NET Framework 4.8，以及 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。若缺少 WebView2，可在微软页面选择 Evergreen Runtime 安装。 |
| Codex | 当前安装流程需要本机已安装 Codex 桌面客户端，并且可运行本机 Codex CLI、使用 ChatGPT 账号查询额度。程序可从已安装的客户端定位配套 CLI。 |
| 网络 | 查询额度时需要能够访问 Codex 的额度服务。 |

安装面向当前 Windows 用户，正常使用无需管理员身份。使用完整安装包时，无需自行安装项目的开发依赖。

## 下载方法

1. 打开本项目的 [Releases 下载页](https://github.com/huang0732/QuotaRing/releases)。
2. 选择需要安装的 QuotaRing 版本，在该版本的 **Assets（附件）** 中下载 **Windows x64 安装包 ZIP**。首发安装包名称为 `QuotaRing-Windows-x64-v1.0.0.zip`。
3. 同时下载该版本的 `SHA256SUMS.txt`，可用其中的 SHA256 值核对安装包是否完整。
4. 将 ZIP **完整解压到一个文件夹**，不要直接在压缩包内运行安装脚本，也不要只单独取出某个 `.cmd` 或 `.exe`。

> 如果 Releases 暂时没有安装包附件，表示安装包尚未发布。GitHub 自动生成的 **Source code (zip / tar.gz)** 是源码压缩包，需要自行构建，不能当作完整安装包使用；当前仓库也尚未上传源码。

## 安装方法

1. 先按上面的运行要求安装所需组件，并确认 Codex 在本机已登录、能够正常使用。
2. 打开完整解压后的 QuotaRing 文件夹，双击 **`安装-Windows.cmd`**。
3. 等待安装和后台启动完成，再等待额度读取。正常情况下，任务栏右侧会出现额度显示条。
4. 点击显示条，确认上方详情卡中的额度和重置时间能够显示。

安装完成后，QuotaRing 默认随 Windows 登录启动。你仍然使用原来的 Codex 图标打开 Codex，额度显示不依赖额外的 Codex 启动入口。

请保留完整的解压文件夹，方便后续手动启动、诊断和卸载。

## 使用方法

### 查看和收起详情

- **点击任务栏额度显示条：** 在其正上方打开详情卡。
- **再次点击显示条、点击卡片外部或按 Esc：** 收起详情卡。
- **关闭 Codex 桌面窗口：** QuotaRing 的额度后台仍继续工作。
- **登录 Windows：** 默认自动启动；如需手动启动，可双击解压文件夹中的 **`启动-Windows.cmd`**。

当前显示位置是**主显示器的任务栏**，不提供每个显示器各显示一份的功能。

### 圆环和小标记分别表示什么

| 显示内容 | 含义 |
| --- | --- |
| 圆环和百分比 | 剩余额度。例如 `34%` 表示该额度窗口还剩约 34%。 |
| 5 个小圆点 | 对应五小时额度窗口，亮起数量表示距离重置还有多少小时，向上取整，最多 5 点。 |
| 7 个小竖条 | 对应周额度窗口，亮起数量表示距离重置还有多少天，按连续 24 小时算一天，向上取整，最多 7 条。 |
| `—` | 当前没有可用于该项显示的数据，不代表额度已经用完。可能是重置时间未知、查询失败或额度窗口不匹配。 |

例如，距离五小时额度重置还有 **4 小时 59 分钟**时，仍亮 5 点；到剩余 4 小时时变成 4 点。距离周额度重置还有 **6 天 23 小时**时，仍亮 7 条；到剩余 6 天时变成 6 条。不足最后一小时或一天时保留 1 个亮起标记，到重置时点归零，读取到新的重置时间后重新计算。

**小圆点和小竖条表示重置倒计时，不表示额度消耗量。** 剩余额度看圆环和百分比。额度正常约每 60 秒查询一次，也会处理服务端推送的额度更新；倒计时在本机每秒更新，因此它不是每发一条消息就立即变化的实时计数器。

### 不同账号的显示情况

| 账号类型 | 当前显示规则 |
| --- | --- |
| Plus | 显示五小时额度和周额度两个圆环；缺失的对应数据会显示为不可用。 |
| Pro | 显示一个周额度圆环；没有对应周窗口时显示 `—`。 |
| Free 及其他账号 | 沿用上游的单环选择规则，部分额度周期暂未接入任务栏圆环。 |

**已知的 Free 账号显示限制：** 部分 Free 账号会返回 30 天额度窗口。详情卡可以列出这个窗口的剩余比例和重置时间，但任务栏圆环当前可能显示 `—`，卡片标题也可能提示“暂时无法读取”，即使卡片中已经列出有效额度数据。首发版保留这一显示限制。

额度和重置时间以服务端实际返回为准。重置卡数量及最近到期时间仅在接口返回相应信息时显示。

## 暂停显示与诊断

如果面板暂时看不到，先退出全屏应用，确认任务栏已经展开，再双击 **`启动-Windows.cmd`**。如仍未显示，双击 **`诊断-Windows.cmd`** 查看后台和显示组件状态。

需要使用命令行时，在完整解压的文件夹中打开 PowerShell，执行对应命令：

```powershell
# 临时停止额度后台和显示窗口
node manage.cjs stop

# 再次启动
node manage.cjs start

# 查看运行状态
node manage.cjs status
```

临时停止不会移除登录自启设置；下一次登录 Windows 时仍会启动。若不希望随登录启动，可以在同一文件夹中执行：

```powershell
node manage.cjs install --no-auto-start
```

这会更新安装设置并继续启动当前面板。以后需要自动启动时，重新双击默认的 `安装-Windows.cmd` 即可。

## 卸载方法

1. 打开先前完整解压的 QuotaRing 文件夹。
2. 双击 **`卸载-Windows.cmd`**，等待提示卸载完成。
3. 确认任务栏显示条已经消失。
4. 卸载完成后，可以再删除下载的 ZIP 和解压文件夹。

卸载会停止额度后台和显示窗口、移除插件自己的登录启动项，并删除插件已知的安装文件和专用显示缓存。如果本机还存在早期版本保存的快捷方式或登录设置备份，会按备份尝试恢复；后来被用户修改的项目不会被直接覆盖。

**卸载会保留 Codex 客户端、Codex 账号登录和聊天记录。** 未知用户文件也会保留，因此安装目录可能不会被整个删除。当前卸载使用直接删除插件文件的方式。

如果解压文件夹已经误删，可以重新下载、完整解压**同一版本安装包**，再运行其中的 `卸载-Windows.cmd`。不要只删除任务栏窗口或登录启动项来代替完整卸载。

也可以在完整解压的文件夹中打开 PowerShell 执行：

```powershell
node manage.cjs uninstall
```

## 常见问题

**为什么显示 `—`？**

先点击显示条查看详情卡。如果详情中已有 30 天额度等数据，可能是上面说明的额度窗口显示限制。如果详情也没有有效数据，请检查本机 Codex 登录、网络和运行组件，再运行诊断脚本。程序查询失败后会自动重试。

**为什么全屏视频或游戏时面板消失？**

这是预期行为。QuotaRing 会暂时隐藏以避免遮挡画面，退出全屏后恢复。任务栏自动隐藏时也会跟随隐藏。

**只用 VS Code、IDEA，或切换账号时，会自动显示对应额度吗？**

面板显示的是其后台读取进程所使用账号的额度。当前未提供多账号同时展示，也没有可靠跟随其他客户端切换账号的机制；IDE 的独立登录环境尚未逐一验证。API Key 的计费额度不在当前支持范围内。

**如何更新版本？**

当前没有自动更新。后续请从本项目 Releases 下载新版本完整安装包，解压后运行其中的 `安装-Windows.cmd`。

## 隐私与项目来源

QuotaRing 通过本机 Codex CLI 的额度查询接口读取数据，不需要向插件粘贴 API Key、Cookie 或访问令牌。插件不读取聊天内容或会话数据库，不启动模型任务，也没有新增遥测上传。显示窗口接收额度显示所需的数据；账号登录与额度服务通信由本机 Codex CLI 处理。

反馈问题时，请先检查截图和诊断内容，移除账号信息、令牌、聊天内容及不希望公开的本机路径。

本项目基于 [Lorie7813/codex-usage-card](https://github.com/Lorie7813/codex-usage-card) 的 macOS v0.9.4 版本二次开发，制作 Windows 任务栏显示和独立后台读取部分，并使用自己的项目名称与版本编号。沿用原项目 MIT 许可证，源码和安装包会保留原始版权声明及相关组件许可证。

QuotaRing 为独立维护的非官方工具，与 OpenAI 无官方关联。项目从 v1.0.0 开始独立编号；当前主要在开发者设备上验证，不同 Windows 环境和未来 Codex 版本的兼容性仍需继续确认。
