# QuotaRing Windows 验证记录

## v1.0.1 验证记录

以下为 v1.0.1 发布前完成的检查。隔离测试未替换开发者当前已安装的插件；另一台电脑的实际安装验收仍待完成。

- 显示组件已本地构建；程序产品/文件版本同步到 1.0.1，清单中的程序集身份 1.0.0.0 保留。
- 使用 Node.js 24.22.2、正常 Windows 权限下完整自动化测试 74/74 通过，0 失败、0 跳过。
- 新增 18 个任务栏位置场景，覆盖右侧优先、右侧拥挤时左移、天气/小组件、左对齐、当前位置稳定、内部空白、缩放、负坐标和全满隐藏。本机 Windows 11 实际检测到开始、搜索、应用和通知区域的坐标；原生窗口进一步验证左移后尺寸不变、详情卡跟随、全满隐藏、恢复显示和检测失败隐藏。左对齐与小组件通过模拟布局验证，未改变当前 Windows 设置。
- 已测试内置 Node 的安装、升级、停止与重启、运行文件占用保护和卸载；保留运行目录中的未知文件及系统已有 Node。
- WebView2 已有、缺少后取消、下载安装成功、签名不可信、下载重定向异常、下载不完整及安装失败分支均有隔离测试；拒绝依赖安装时，旧 QuotaRing 安装文件和配置保留。
- WebView2 安装进程无响应时最长等待 3 分钟，超时返回并保留旧安装和可能仍在使用的临时文件。使用短等待时间的模拟测试覆盖超时、正常退出、启动失败、中断及延迟事件；另使用真实的模拟子进程确认父进程能够退出、微软安装程序采用的独立启动方式不会随之被回收。等待上限从 10 分钟缩短后，固定值检查同步为 180000 毫秒；未为测试等待真实的 3 分钟或运行微软安装。
- 当前设备已有 .NET Framework 和 WebView2 Runtime，实际检测成功。微软引导程序已实际下载并通过 Microsoft Corporation 签名检查，未运行该安装程序。
- 本次未在缺少 WebView2 的干净 Windows 系统上执行真实安装；组织策略、首次 Runtime 安装、需要重启的情况和 Windows 10 仍未实机验证。
- 实际 ZIP 解压后，在 PATH 不含系统 Node 的情况下，四个中文入口均调用包内 v24.22.2 并正确转发参数；实际内置 Node 与原生面板的隔离安装、重复启动、停止重启、覆盖安装和卸载检查通过。
- 安装包为 `QuotaRing-Windows-x64-v1.0.1.zip`，体积与校验值以对应 Release 附件和 `SHA256SUMS.txt` 为准。v1.0.0 旧包和旧校验文件保留。
